OOP 1 PROJECT
Wildcats Lounge

Overview

A POS and Staff Management System developed for the Object-Oriented Programming 1 course. The system manages point-of-sale operations, staff scheduling, attendance, and allowance computation for a simulated café lounge environment.

Technologies Used

C#Windows Forms Visual Studio 2022Microsoft Access (.mdb) OleDbQRCoder SHA-256PrintDocument PrintPreviewDialog

System Roles

  • Manager — Full access; daily allowance: ₱100
  • Cashier — POS operations; hourly allowance: ₱25/hr
  • Barista — Order fulfillment; hourly allowance: ₱25/hr

System Features

  • POS operations and product management
  • Sales tracking and reporting
  • Staff management with time-in/time-out
  • Attendance tracking and allowance computation
  • Inventory reporting and management
  • Receipt generation with PrintDocument/PrintPreviewDialog
  • QR / eCash payment support via QRCoder
  • Role-based account management
  • Password hashing with SHA-256

Challenges

  • Role management implementation
  • Database CRUD operations with OleDb
  • UI design for multiple user types
  • Analytics and reporting logic
  • Inventory transaction management
  • Attendance and allowance automation

Key Learnings

  • Database connectivity using OleDb
  • Password handling using SHA-256
  • UI design with Windows Forms
  • Error handling and input validation
  • File and image management
  • Sales and attendance automation
  • Allowance computation logic

Future Improvements

  • Migration to SQL Server or SQLite
  • Barcode scanner integration
  • Loyalty and rewards system
  • PDF/Excel report export
  • Graphical analytics dashboard
  • Improved QR/e-wallet support
  • Query optimization and real-time inventory
  • Enhanced security and session management
  • Reusable helper classes
